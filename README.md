Este projeto é uma simulação de um catálogo de filmes, com foco em praticar a parte visual (front-end) e a lógica de autenticação de usuários. Ele permite que o usuário realize um cadastro e um login, armazenando as informações localmente com localStorage.

Após um cadastro e login bem-sucedidos, o usuário é redirecionado para a tela principal, onde pode navegar pelo catálogo de filmes, analisando as opções com calma e escolhendo qual deseja assistir no momento.
